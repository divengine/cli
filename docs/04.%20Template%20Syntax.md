# Template Syntax

Div CLI uses the divengine/div template engine with `{$variable}` syntax.

## Variable Substitution

```tpl
Hello, {$name}!
```

With data `{"name": "World"}`, outputs: `Hello, World!`

## Nested Variables

```tpl
User: {$user.name}
Email: {$user.contact.email}
```

## Arrays

```tpl
First item: {$items[0]}
Count: {$items|count}
```

## Conditions

```tpl
{if $user.active}
  Welcome back, {$user.name}!
{else}
  Please activate your account.
{end}
```

## Loops

```tpl
{loop $items as $item}
  - {$item}
{/loop}
```

## Modifiers

```tpl
{$name|upper}
{$date|date:"Y-m-d"}
{$text|truncate:80}
```

## Comments

```tpl
{* This is a comment *}
```
